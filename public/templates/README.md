# Template Screenshots — Capture Guide

Drop your 8 template screenshots in this folder. The home page
auto-loads them. While files are missing, each tile shows a
gradient placeholder so nothing breaks.

## Required filenames

Save each as **`.webp`** (preferred — smaller) OR **`.png`**:

| File | Template |
|------|----------|
| `template-classic.webp`   | Classic |
| `template-modern.webp`    | Modern |
| `template-executive.webp` | Executive |
| `template-studio.webp`    | Studio |
| `template-wave.webp`      | Wave |
| `template-bold.webp`      | Bold |
| `template-frost.webp`     | Frost |
| `template-editorial.webp` | Editorial |

## Capture spec

- **Aspect ratio:** 2:3 portrait (e.g. 600×900, 800×1200, 1000×1500)
- **Format:** WebP at quality 85, OR PNG if WebP isn't an option
- **File size:** under 250 KB per image after compression
- **Content:** use the **same card data** for every screenshot so
  the visitor sees "same person, 8 different vibes". Suggest:
  - Your own real Cardtly card, OR
  - A demo card with: name, title, company, real photo, 1 link,
    2-3 contact rows, a clear save-contact button visible

## The fastest capture workflow

1. Sign in to Cardtly and open your card editor at `/dashboard/card`
2. Make sure your card has: profile photo, name, title, company, bio,
   phone, email, website (and links if you use them) — a populated
   card always looks better than an empty one
3. In Design panel → Template tab, switch to template 1 of 8 (Classic)
4. In a new tab open `https://cardtly.com/card/<your-slug>`
5. Open Chrome DevTools → toggle device toolbar → set
   **Responsive 400 × 600** and zoom out so the whole card fits
6. Right-click → "Capture full size screenshot" (or use Cmd/Ctrl + Shift + P → "Capture full size screenshot")
7. Crop to the card frame (Preview / Snipping Tool / Photoshop)
8. Save as `template-classic.webp` (or .png)
9. Back to the editor → switch template → repeat for the other 7

Total time: ~20 minutes for all 8 if you're moving.

## Alternative — Figma / mock data

If you'd rather use designer-made mocks instead of real data, that's
also fine. Just keep them all at the same aspect ratio and same
content so the grid feels cohesive.

## Don't forget

- Pro-only templates (everything except Classic) show fine in
  preview because you have a comped Pro account
- Resist the urge to over-polish — the templates should look like
  they look in real life, not better
- The hover state on each tile adds a "Try this template" pill
  automatically; you don't need to include CTA text in the image
